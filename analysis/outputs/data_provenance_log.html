Terms used in this document. Repeat = the user bought on 2 or more different days (WIB), counting valid non-bonus purchases only. Mature = first purchase at least 120 days before the data pull (2026-11-22), so every user had the same time to buy again (first purchase on or before 2026-07-25). Mature repeat = % of mature investors who are repeat. Rates on non-mature users are not comparable. Data window = all registrations and transactions up to 2026-11-22 unless a section states another window (GA4 events: 2026-10-01 to 2026-11-21, 52 days). Raw file = path under analysis/outputs/.
