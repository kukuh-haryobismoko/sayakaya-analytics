Profile fields (gender, age, occupation, income, city) are filled only after KYC, so for those cuts the useful denominator is approved users. For approved users the 'Investor % of approved' column is the fair comparison; the (null) rows are users who never reached the profile step.   • Observed: with a referrer code (not RAIZ/RAIZKAYA): 6,330 registered, 3,356 approved, 1,328 investors = 21.0% of registered (20.0-22.0%). No code (NULL or empty): 57,944 registered, 13,625 approved, 2,289 investors = 4.0% of registered (3.8-4.1%). z = 55.8. Referral codes: 660 distinct.
