Scope: the uncommitted diff only (fund/MI share %, donut %, AUM history root cause + per-fund drill, new Top investors section). Pre-existing app-wide patterns are listed only where the diff adds to them.

Design Read: internal analytics dashboard for SayaKaya ops/finance staff, built on the app's existing design system (tokens in `public/styles.css`, `.panel`, `.seg`, `.table-wrap`, Chart.js palette `C.*`), dial ENERGY 1 / RHYTHM 1 / MOTION 1. Nothing is changed until you pick numbers.

## HIGH (Hard Gate)

1. **R-25, light-theme contrast of signed amounts.** AUM history's new Net flow and Market effect columns (and the existing Δ AUM % column) color text with `--teal` and `--rose`. On white: teal 2.22:1, rose 3.57:1, both under 4.5:1. Dark theme passes (11.05:1, 7.15:1). Direction is not color-only (every value has a +/− sign). Fix: add darker light-theme text tokens for positive/negative (dark theme keeps the current ones) and use them in these cells.

2. **R-32, clickable AUM rows.** Rows open the drill on click and Enter, but not Space, have no button semantics for screen readers, and the focus ring on a `<tr>` renders inconsistently across browsers. Fix: render the period in the first cell as a real `<button class="link-btn">` (native Enter/Space/focus), drop `tabindex` and the custom keydown handler, keep the row click for mouse users.

3. **R-27, "What moved AUM" chart has no empty or error state.** With 0 or 1 period in range it draws empty axes with no message. If the fetch fails, the previous chart stays on screen while the table shows the error. Fix: hide the canvas and show a message ("Needs at least two periods. Widen the date range.") when there is nothing to explain, and on error.

4. **R-03, tap targets under 44px on mobile.** The new filter bar adds 7 `.seg` buttons (about 26px tall) plus Run/CSV/Excel (about 32 to 34px). `.seg` is the app-wide segmented control, so the real fix touches every section. Fix option: a mobile-only rule (`max-width: 900px`) that raises `.seg button`, `.btn-primary`, and `.btn-ghost` to a 44px touch height. Changes every section on phones.

5. **R-03, possible overflow at 320px (unverified).** The Subscribers / Redeemers / Net deposit control is about 266px wide and cannot wrap; at a 320px viewport the panel leaves about 268px. It likely fits, but by 2px. Fix if it overflows in a browser: let `.seg` wrap on narrow screens.

6. **R-35, no browser click-through yet.** No browser tool was available in this session. What was verified: stubbed-DOM smoke test renders `#aumTable`, `#aumDrillTable`, `#tiTable`, `#topFunds` with the new values; every query ran against BigQuery (August drill sums to the platform ΔAUM exactly). Still needed, in a real browser, both themes, desktop and 375px: Top investors metric buttons, Day/Week/Month/Custom (Custom shows From/To), Top N + Run, CSV/Excel; AUM history row click opens the drill and scrolls to it, drill CSV/Excel; Largest funds % column; donut legends show %. I cannot close this one myself.

8. **R-02, "—" for empty cells.** New null cells (first-row Market effect, missing % of total) show "—". This is the app-wide null placeholder (`genTable` does the same everywhere), not prose. Recommend skip for consistency.

9. **R-27 copy, Top investors empty state.** "No completed transactions in this period." names the cause but not the next step. Fix: "No completed buys or sells in this period. Pick a wider period or use Custom."

10. **Non-text contrast of the cause-chart bars (light theme).** Net flow uses teal (2.22:1 on white), Market effect uses amber (1.58:1), under the 3:1 bar for chart marks. This is the app's shared chart palette (the AUM, Overview, and Revenue charts use the same colors); the legend and tooltip carry the labels as text. Recommend skip unless the chart palette is revisited app-wide.
